# GittyUp 2025

A starter personal portfolio website built with plain HTML and CSS. Currently a
placeholder page that will grow into a full portfolio.

## What it does

- `index.html` — the page structure (currently a simple heading).
- `style.css` — reserved for styling.

## Requirements

- Any web browser

## Install

No dependencies. Just clone the repo:

```bash
git clone https://github.com/kunal4060/GITTYUP-2025.git
cd GITTYUP-2025
```

## Usage

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```
